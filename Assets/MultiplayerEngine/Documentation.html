🚀 Setup Guide

Requirements

  • Unity 2022.3 LTS or newer
  • Netcode for GameObjects package
  • Unity Services Core (for Unity Services mode)
  • Facepunch.Steamworks (for Steam mode)

Installation Steps

Import the Package

Import Multiplayer Engine Pro from the Unity Asset Store or your package folder into your Unity project.

Configure Scripting Defines

Go to Edit > Project Settings > Player > Scripting Define Symbols

Add one of the following:

UNITY_SERVICES    // For Unity Gaming Services
STEAM_SERVICES    // For Steam integration

Setup Unity Services (if using UNITY_SERVICES)

  • Go to Edit > Project Settings > Services
  • Link your Unity project
  • Enable: Authentication, Lobby, Relay, Cloud Save, Vivox

Configure the NetworkManager

Open the Lobby scene and locate the NetworkManager object:

  • Ensure UnityTransport is attached (for Unity Services)
  • Or SteamNetworkingSocketsTransport (for Steam)

Setup Player Prefabs

Add your character prefabs to the PlayerProfileManager:

  • Create a CharacterData ScriptableObject for each character
  • Assign the prefab and character ID
  • Add to the CharacterData list in PlayerProfileManager

Configure Scenes

Add your scenes to Build Settings in order:

  1. Lobby - Main menu and lobby
  2. Game - Your gameplay scene
⚠️ Important

Make sure only ONE service define is active at a time. Having both UNITY_SERVICES and STEAM_SERVICES will cause compilation errors.

🏠 Lobby System

Overview

The lobby system manages the pre-game experience where players gather, select characters, and prepare for the match. It's built around the LobbyManager singleton that handles all lobby operations.

Key Components

Component Purpose
LobbyManager Core lobby functionality (create, join, leave, update)
SessionManager Handles game session transitions and scene loading
AuthenticationManager User sign-in and authentication
FriendsManager Friends list and invites
VoiceManager Voice chat in lobby

Creating a Lobby

// Create a public lobby with max 4 players
await LobbyManager.Instance.CreateLobby(
    lobbyName: "My Awesome Lobby",
    maxPlayers: 4,
    isPrivate: false,
    gameMode: GameMode.FreeForAll
);

Joining a Lobby

// Join by lobby ID
await LobbyManager.Instance.JoinLobby(lobbyId);

// Join by code
await LobbyManager.Instance.JoinLobbyByCode(joinCode);

Lobby Events

// Subscribe to lobby events
LobbyManager.OnLobbyCreated += HandleLobbyCreated;
LobbyManager.OnLobbyJoined += HandleLobbyJoined;
LobbyManager.OnLobbyUpdated += HandleLobbyUpdated;
LobbyManager.OnLobbyLeft += HandleLobbyLeft;

Player Ready System

// Toggle ready state
await LobbyManager.Instance.UpdateReadyState(isReady: true);

// Start game when all players ready (host only)
await LobbyManager.Instance.StartGameAsync();

Game Modes

FreeForAll

Every player for themselves. Last one standing wins.

TeamDeathmatch

Two teams compete. Team with most eliminations wins.

CaptureTheFlag

Capture the enemy flag while defending your own.

🎭 Character System

Overview

The character system provides a complete third-person controller with networked movement, animations, and interaction capabilities.

Core Components

Component Description
PlayerController Handles interactions, object pickup, and player logic
ThirdPersonController Movement, jumping, camera control
HealthManager Health tracking and damage processing
WeaponManager Weapon handling, aiming, and IK

ClientNetworkAnimator Networked animation sync

Setting Up a Character Prefab

Add Required Components

Add these components to your character root:

  • NetworkObject
  • PlayerController
  • ThirdPersonController
  • HealthManager
  • WeaponManager
  • ClientNetworkTransform
  • ClientNetworkAnimator
  • CharacterController
  • PlayerInput

Configure Animator

Ensure your Animator has these parameters:

  • Speed (float) - Movement speed
  • Grounded (bool) - Is on ground
  • Jump (bool) - Jump trigger
  • FreeFall (bool) - Falling state
  • MotionSpeed (float) - Animation speed multiplier

Create CharacterData

Create a CharacterData ScriptableObject:

// Right-click > Create > MultiplayerEngine > CharacterData
// Set:
// - CharacterId: unique identifier
// - CharacterPrefab: your prefab reference
// - DisplayName: shown in UI
// - Icon: character portrait

ThirdPersonController Settings

Property Default Description
MoveSpeed 2.0 Walking speed
SprintSpeed 5.335 Running speed
JumpHeight 1.2 Jump height in meters
Gravity -15.0 Custom gravity value
RotationSmoothTime 0.12 Character rotation smoothing

Health System

// Get health manager reference
HealthManager health = GetComponent<HealthManager>();

// Take damage
health.TakeDamage(new DamageMessage(
    sender: attackerTransform,
    hitPoint: hitPosition,
    damage: 25,
    source: "Sword"
));

// Heal
health.Heal(20);

// Reset to max health
health.ResetHealth();

Interaction System

The PlayerController automatically detects nearby Interactable objects:

  • Interact Radius: Detection range (default: 2.0)
  • Interact Angle: Field of view for detection (default: 60°)
  • Check Interval: How often to scan (default: 0.1s)

⚔️ Weapon System

Overview

The weapon system supports both melee and ranged weapons with full networking support, IK-based hand positioning, and smooth aiming mechanics.

Weapon Types

🗡️

Melee Weapons

Close-range weapons like swords, axes, and hammers. Uses animation events for damage timing.

🔫

Shooter Weapons

Ranged weapons with projectiles. Supports Auto and Single fire modes with configurable fire rates.

MeleeWeapon Setup

Property Description
weaponModel The visual model Transform
weaponHolder Which hand bone to attach to (default: RightHand)
pickupPosition Local position when held
pickupRotation Local rotation when held
attackAnimationTrigger Animator trigger name (default: "MeleeAttack")
attackCooldown Time between attacks (default: 0.5s)

ShooterWeapon Setup

Property Description
projectilePrefab The bullet/projectile prefab
muzzlePoint Where projectiles spawn from
fireRate Shots per second
shootMode Auto (hold to fire) or Single (tap to fire)
muzzleFlash Optional muzzle flash effect
shootSound Audio clip for firing

Fire Modes

public enum ShootMode
{
    Auto,    // Hold fire button for continuous shooting
    Single   // Each press fires once
}

WeaponManager

The WeaponManager component handles:

  • Current weapon tracking
  • Aiming state and camera integration
  • IK positioning for left and right hands
  • Smooth weapon transitions
  • Input handling for aim/fire

Creating a Custom Weapon

Create the Prefab

Create a new prefab with a NetworkObject component at the root.

Add Weapon Script

Add either MeleeWeapon or ShooterWeapon component.

Configure References

Set up the weapon model, IK hints, and any effects (particles, audio).

Set Pickup Properties

Configure holdPosition and holdRotation in the Pickable base class.

💡 IK Tips

Create empty GameObjects for left/right hand hints and IK targets. Position them relative to the weapon model for natural hand placement when aiming.

❓ Frequently Asked Questions

General

Q: Can I use this for mobile games?

A: Yes! When using Unity Services mode, the asset is fully cross-platform. Steam mode is PC-only.

Q: Do I need a dedicated server?

A: No. The asset uses Unity Relay (or Steam P2P) for host-based networking. One player acts as the host.

Q: How many players are supported?

A: Unity Lobby supports up to 100 players per lobby. Practical limits depend on your game design.

Technical

Q: Why am I getting compilation errors?

A: Ensure you have exactly ONE scripting define set (UNITY_SERVICES OR STEAM_SERVICES), not both.

Q: Voice chat isn't working?

A: For Unity Services, ensure Vivox is properly configured in the Unity Dashboard. For Steam, verify Steamworks SDK integration.

Q: Characters aren't spawning correctly?

A: Check that: 1) SpawnManager has spawn points assigned, 2) Character prefabs are registered, 3) Player has selected a character in lobby.

Customization

Q: How do I add custom death behavior?

A: Create a class that inherits from HealthManager and override the OnDeath() method.

Q: Can I add new game modes?

A: Yes! Add new values to the GameMode enum and implement the corresponding logic in your game scene.

Q: How do I customize the UI?

A: All UI components are in the Scripts/Lobby/UI folder. Modify the prefabs in Prefabs/Lobby for visual changes.
